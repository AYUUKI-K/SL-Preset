# SL 预设 · 在线更新试用版

by NUE-喵喵电波

基于 `[MoM]✩‧₊SL 5.3 @NUE` 增加预设内置更新脚本。原有 70 个提示词条目、11 条正则、3 个配套脚本及其分组保留。需要 SillyTavern 的聊天补全预设功能和已启用的酒馆助手。

## 导入和试用

1. 从 [downloads 文件夹](https://github.com/AYUUKI-K/SL-Preset/tree/main/downloads) 下载名称带“自动更新”的 JSON。
2. 在酒馆的聊天补全预设页面导入并选择它。名称带“自动更新”，方便与原版并存。
3. 默认在选择预设后约 8 秒检查一次，之后每 30 分钟检查；有新版时在酒馆空闲时自动应用。生成中或其他弹窗打开时等待空闲。
4. **没有更新按钮、面板或额外样式**，不改变预设栏布局。没有新版本时保持安静；成功更新时使用酒馆已有的短提示。
5. 更新后刷新酒馆，使原配套脚本完整重新加载。程序不会强制刷新正在使用的酒馆。

当前发布为 **5.3.1 / revision 2**，移除了上一版的按钮和面板。已经导入 5.3.0 的用户请重新导入并选中新版，再刷新一次酒馆；上一版默认只检查，不会自行安装这次更新。新版本忽略旧版保存的 `autoCheck/autoApply=false`，直接按新的自动更新规则运行。

## 更新规则

- 提示词、正则、脚本用各自的固定 ID 匹配。ID 保持不变时，作者可以更新正文和名称。
- 默认同步作者发布的预设名称，更新后酒馆下拉框会使用新版名称。存在同名预设时停止，避免覆盖另一份预设。
- 默认保留条目开关、正则停用状态、脚本启用状态和数据、用户新增条目、脚本及正则、酒馆助手变量。
- 默认按字段保留本地修改。例如用户改写了正文，但没有改标题，更新可保留正文并同步作者的新标题。用户自行新增的内容也保留。
- 未改动且被作者删除的条目会移除；手改过的正文默认保留。用户自行删除的原条目不会在每次更新时复活。
- 默认保留本机采样参数。旧版已保存的名称同步、内容保留和采样参数偏好继续沿用。
- 只更新这份预设绑定的正则和脚本，不操作全局或角色卡的正则、脚本。原脚本对世界书或 QR 的既有行为仍由原脚本自身决定。
- 柏宝箱分组名称和作者配置同步；已有分组的展开状态和启用状态保留。其他插件的私有扩展数据保留。

## 备份和恢复

每次写入前在**当前浏览器、当前酒馆地址**的本地存储保留最近一份备份，包含当前未点击保存的预设内容。无按钮版本不提供独立恢复面板；需要恢复时，可在酒馆网页的开发者工具控制台复制备份 JSON，再保存为 `.json` 并用酒馆原生预设导入功能恢复：

```js
copy(JSON.stringify(window.__NUE_SL_PRESET_UPDATER__.getBackup()?.active, null, 2))
```

恢复旧版前可在酒馆助手中停用“SL · 预设在线更新”脚本，避免再次自动升级。

备份不是云端备份。更换浏览器、酒馆域名、清理站点数据后无法从原位置找回，请另存重要备份。浏览器存储满时更新会停止。网络写入失败时不删除原预设；请求期间发生切档、编辑或生成时，不用旧快照刷新当前页面。临时网络错误只记录到控制台，等待至少半小时再试。

重命名会改变酒馆的实际预设名称。**通过旧名称引用预设的连接配置、自动化命令或其他插件，可能需要手动改成新名称。** 有这类绑定时，可以通过以下开发者工具控制台设置保留本机名称，然后刷新酒馆：

```js
const k = 'nue.sl.updater.nue.sl.preset';
localStorage.setItem(k, JSON.stringify({ ...JSON.parse(localStorage.getItem(k) || '{}'), rename: false }));
```

## 作者发新版

1. 从酒馆导出编辑后的预设，替换 `source/preset.json`。不要把用户 API Key、代理密码或私人服务地址放进发布文件。
2. 编辑 `release.json`：每次发布都把 `revision` 加 1，再填写 `version`、`displayName` 和 `changelog`。内部 `presetId` 保持不变；原条目 ID 保持不变。
3. 提交 `source/preset.json` 和 `release.json` 到 `main`。GitHub Actions 自动打包、运行回归检查、提交 `dist/`、`downloads/` 和 `update.json`。
4. Actions 成功后，新版用户可直接下载 JSON；使用无按钮版的已有用户会在空闲时自动更新。GitHub Raw 网络不可达时可手动导入 JSON。

也可以本地执行：

```powershell
npm run build
npm test
```

没有安装依赖的要求。需要 Node.js 22 或更高版本。脚本源码在 `src/`，构建脚本在 `tools/build.mjs`。

## 验证范围

自动化验证覆盖无页面控件、默认自动更新、旧版关闭设置迁移、空闲等待、重试间隔、完整打包保真、摘要检查、字段合并、重命名、开关及自定义内容保留、备份失败、网络失败和切档竞态。`node tests/browser-host.mjs` 提供隔离的本地模拟宿主；它不执行原有配套脚本、不调用模型、不接触实际酒馆存档。

当前已完成上述回归及模拟宿主测试，**尚未在用户实际酒馆中完成整套联调**。使用原始预设管理器接口以保留酒馆助手标准化接口以外的字段；较旧或修改过预设管理接口的宿主可能不兼容。

## 实现来源

更新器为本仓库实现，使用 GitHub 发布文件和预设内置脚本的思路，参考 [青空莉的酒馆助手模板](https://github.com/StageDog/tavern_helper_template)。该模板的“脚本通过远程链接更新”不会自动赋予整份预设同步能力；本仓库额外实现版本清单、内容合并、改名和备份。运行接口参考 [SillyTavern 预设管理器](https://github.com/SillyTavern/SillyTavern/blob/release/public/scripts/preset-manager.js) 和 [酒馆助手脚本结构](https://github.com/N0VI028/JS-Slash-Runner/blob/main/%40types/function/script.d.ts)。

原预设及配套内容的署名和使用约定保留；本仓库不额外授予这些内容的再分发许可。
